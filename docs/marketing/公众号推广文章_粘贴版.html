Auto-Continue 已经支持 Codex 了。无论你使用 Codex 桌面版，还是在 Windows Terminal 中使用 Codex CLI，都可以让它监测会话，在符合条件时自动续接。原有的 Claude CLI 支持也继续保留。

这次值得看什么？

用 Codex 的朋友，先看桌面版与 CLI 能做什么；已经用过 Auto-Continue 的朋友，可以重点看新的分类界面、会话设置和权限开关。第一次使用，文末有三步入门。

配图版本说明：本文展示已公开发布的 Auto-Continue 3.0.0 界面，包含三个切换栏、最近活动设置与自动工具权限批准。配图为原生界面高清截取，字号放大以便阅读；拍图实例暂停监测，活动记录来自真实会话。

长任务最烦的，是停下来没人接

让 AI 检查代码、修改项目、跑测试，任务一长，就容易遇到这些时刻：

  • 额度暂时用完，恢复后还得回来手动发“继续”。
  • 连接出了问题，会话停在重试提示上。
  • 当前一轮已经完成，下一步检查还没开始。
  • 几个会话同时开着，模型和续接要求各不相同。
  • 人在忙别的事，很晚才发现窗口早已停住。

第一次听说 Auto-Continue？

AI 助手负责做任务，Auto-Continue 负责观察会话状态。遇到已识别、允许续接的暂停，它按设置等待或重试；完成当前一轮后，也可以发送你预先写好的下一步要求。你仍然决定任务内容、续接次数和哪些会话要监测。

01 / Codex 桌面版、CLI，都能用

Codex 桌面版对应 Codex EXE，命令行对应 Codex CLI。两者与 Claude CLI 分别管理监测状态和设置，适合在同一台电脑上按需要启用。

本机新版把三类入口放在平等的切换栏中。选中哪一类，就显示对应的设置和会话；想同时监测多类，可以分别开启。日志留在最下面，便于回看续接过程。

▲ 本机新版原生高清图。三个类型各有入口，设置按当前选项呈现。

02 / 多个会话，分别安排

本机新版的 Codex EXE 页面默认列出最近 5 条 Codex 活动，数量可自定义。每条记录都能独立配置模型、推理强度、是否排除，以及完成后发送什么提示。即使两个会话标题相同，设置也按各自的会话保存。

▲ 本机新版原生高清图，裁取表格右侧。五条记录都有独立设置入口；图中有运行中的会话，也有已完成的会话。

最近活动列表方便集中查看和配置。自动操作作用于 Codex 窗口中当前可见的会话；后台记录的设置会在该会话显示到窗口后应用。监测范围为 Codex，不包括 ChatGPT 和 ChatGPT Work。

模型设置可以选择保留当前模型，也可以指定模型与推理强度。实际可用的模型和选项，以你的 Codex 版本、账户及原生界面为准。

▲ 本机新版的模型选择菜单，原生高清截图。

03 / 该等就等，该重试再重试

Codex CLI 出现可解析的额度恢复时间时，可以等到恢复时间加上缓冲后再续接。桌面版没有显示恢复时间的情况，则按照重试间隔和次数上限处理。已识别的连接错误也采用有限重试。

▲ 本机新版原生高清图。检查间隔、缓冲、重试间隔可以按使用场景调整。

达到重试上限后，会停下来等你处理。已有输入草稿、会话正在工作，或某些菜单仍打开时，会暂停自动输入；登录失效等问题也需要人工处理。

04 / 做完这一轮，再检查遗漏

如果你的任务是“改完以后再检查”，可以为会话设置 After finish 提示。当前一轮完成、窗口空闲且符合续接条件时，Auto-Continue 会发送这段提示；剩余次数用来限制后续续接。

一个可以按需修改的提示示例

继续检查尚未完成的任务，完成后汇报结果。不要重复已完成的步骤。

▲ 在本机原生设置框中输入的示例，图中剩余次数为 1。
提示写得越具体，后续任务越容易检查。

05 / 本机新版：权限设置有开关

本机新版增加了 Codex 权限模式选择，以及“自动批准权限请求”开关。权限模式默认完全访问，也可以选“帮我批准”或“请求批准”；自动批准默认开启。Codex EXE 与 CLI 的设置分别保存。

▲ Auto-Continue 3.0.0 原生高清图，公开下载包已同步。

开启自动批准，意味着已识别的工具权限请求可以自动通过。如果你希望保留逐次确认，请关闭开关，并选择适合的权限模式。普通提问和其他菜单仍需要你处理。

实际验证到哪里？

2026 年 10 月 4 日，本机更新后的 EXE 已完成启动和界面核验，122 项回归测试通过。Codex CLI 与桌面版还在真实原生窗口中检查了模型与推理强度、草稿保留、忙碌时暂停输入、有限续接，以及重试上限等场景。

额度与连接错误场景使用隔离测试环境注入，验证的是软件如何响应这些状态。桌面版权限卡片已验证，但命令升级审批卡片未完成原生验证，不能据此承诺所有审批窗口都能处理。测试也不代表绕过平台额度、修复登录或保证任务质量。

使用环境Windows；Codex 桌面版 / Codex CLI / Claude CLI
会话范围桌面版操作当前可见会话；CLI 建议每个会话使用独立的 Windows Terminal 窗口
需要人工处理登录失效、未识别状态，以及不属于已支持权限请求的菜单
授权MIT 开源，免费，可商用；AI 平台账户与使用费用按各平台规则处理

三步开始使用

① 下载并解压
从下方下载站或 GitHub 发布页获取 Windows 包，运行 Auto-Continue.exe。

② 打开你要监测的 Codex
保持 Codex 桌面版会话可见；使用 CLI 时，将需要监测的会话放在独立的 Windows Terminal 窗口中。

③ 选择监测类型并启动
按下载版本的界面开启对应监测，确认模型和续接设置，再启动监测。第一次使用，建议先用一个简单任务观察日志；需要完成后追加任务时，再填写 After finish 提示。
